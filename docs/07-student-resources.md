# Student resources

Free tools that help you build and deploy websites as a student.

## GitHub Student Developer Pack

The [GitHub Student Developer Pack](https://education.github.com/pack) is free for verified students and includes many developer tools.

### How to apply

1. Go to [education.github.com/pack](https://education.github.com/pack)
2. Click **Get your Pack**
3. Sign in with GitHub
4. Verify student status with:
   - School email (`.edu`), or
   - Student ID photo, or
   - Enrollment letter / transcript
5. Approval usually takes 1–7 days

### Useful benefits for this project

| Benefit | Why it helps |
|---------|--------------|
| GitHub Pro | Unlimited private repos for client projects |
| Namecheap | Free `.me` domain for testing |
| Various hosting credits | Optional alternatives to Vercel free tier |
| Copilot | AI coding assistance in GitHub |

Even without Cursor Pro, the Student Pack is worth getting for domains and GitHub features alone.

## Cursor for students

### Free tier

Anyone can use [Cursor](https://cursor.com) on the **free Hobby plan** with limited fast AI requests. Enough to learn and make small sites.

### Student Pro discount (as of June 2026)

Cursor **discontinued new sign-ups** for the legacy student discount program in June 2026. Check official sources for current options:

- [cursor.com/students](https://cursor.com/students) — campus events, newsletter, credits
- [Cursor student discount docs](https://cursor.com/help/account-and-billing/student-discount) — official policy

**If you already had student Pro:** You keep your rate until the plan expires.

**For new students:** Look for campus promotions, sign up for the campus newsletter, or request credits if you're a graduate student, researcher, or educator (forms linked from official Cursor student pages).

Do not rely on outdated blog posts promising free Pro via GitHub Student Pack — verify on Cursor's official site.
